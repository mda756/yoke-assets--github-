 🛠️ ADVANCED OPTIONS
═══════════════════════════════════════════════════════════════════════

Pre-configure auth key for silent deployment:
  1. Edit: DEPLOY-COMPLETE-SETUP.ps1
  2. Find line: $TAILSCALE_AUTH_KEY = "PASTE..."
  3. Replace with your actual key
  4. Now runs completely silent!

Add more programs to auto-install:
  1. Edit: AUTO-SETUP-WITH-PROMPTS.ps1
  2. Add more winget install commands
  3. Examples:
     winget install --id Microsoft.PowerToys
     winget install --id Microsoft.VisualStudioCode

Change what auto-starts on login:
  1. Edit: startup-apps.ps1
  2. Add more Start-Process commands

 📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

ISSUE: "Running scripts is disabled on this system"
FIX:  Run this in PowerShell as Administrator:
      Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

ISSUE: Tailscale won't connect
FIX:  Click system tray icon → Sign in manually

ISSUE: GitHub Desktop won't sign in
FIX:  Normal! It opens browser, sign in once, then it remembers

ISSUE: Auto-startup doesn't work
FIX:  Restart PC completely (logout isn't enough)
      Or check: Win+R → type "shell:startup"
