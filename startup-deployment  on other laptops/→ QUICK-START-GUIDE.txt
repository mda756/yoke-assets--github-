║  STEP 1: First-Time Setup (Do Once - 2 Minutes)         ║
╚══════════════════════════════════════════════════════════╝

    ON THIS PC (hwofficepc):

    1. Open file: GET-AUTH-KEY.txt

    2. Browser will open to Tailscale admin

    3. Click "Generate auth key"

    4. Settings:
       ✓ Check "Reusable"
       ✓ Check "Preauthorized"

    5. Copy the key (starts with "tskey-")

    6. Save as "auth-key.txt" in this folder

    ✅ Done! You're ready to deploy!


╔══════════════════════════════════════════════════════════╗
║  STEP 2: Deploy to New Laptop (Repeat - 8 Minutes Each) ║
╚══════════════════════════════════════════════════════════╝

    ON EACH NEW LAPTOP:

    1. Copy entire "startup-deployment" folder
       (USB / OneDrive / Email / Network)

    2. Double-click: INSTALL-ON-NEW-PC.bat
       ┌────────────────────────────┐
       │ INSTALL-ON-NEW-PC.bat      │
       └────────────────────────────┘
       (Just double-click, that's it!)

    3. Click "Yes" when it asks for Admin

    4. Wait 5-7 minutes
       (Coffee break! ☕)

    5. Restart laptop

    6. GitHub Desktop opens → Sign in (one-time)

    ✅ Done! This laptop is fully configured!
