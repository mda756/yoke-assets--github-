TROUBLESHOOTING:
────────────────────────────────────────────────────────────
❌ Window closes immediately?
   → Right-click .bat file → Run as administrator

❌ Installation fails?
   → Script will show which failed
   → Install manually from websites

❌ Nothing happens?
   → Make sure Windows didn't block the file
   → Right-click → Properties → Unblock → Apply
