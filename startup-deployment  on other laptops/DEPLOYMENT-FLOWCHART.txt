│                      ROLLBACK / UNINSTALL                            │
└─────────────────────────────────────────────────────────────────────┘

  Need to remove everything?

  1. Uninstall Programs:
     • Settings → Apps → Uninstall Tailscale
     • Settings → Apps → Uninstall GitHub Desktop

  2. Remove Auto-Startup:
     • Win+R → type "shell:startup"
     • Delete: startup-apps.ps1 and startup-apps.vbs

  3. Clean Git Config (optional):
     • PowerShell: git config --global --unset user.name
     • PowerShell: git config --global --unset user.email
