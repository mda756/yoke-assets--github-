═══════════════════════════════════════════════════════════════════════
  TROUBLESHOOTING (If something fails)
═══════════════════════════════════════════════════════════════════════

If installation window closes immediately:
  → Right-click SIMPLE-ONE-CLICK-INSTALL.bat
  → Select "Run as administrator"
  → Click YES

If Claude shows debug messages or log output:
  → You have an old debug script running
  → Delete this file: %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\startup-debug.ps1
  → Keep only: startup-apps.ps1
  → Restart the computer
  → FIXED: 04-Feb-2026 (removed from this laptop)

If a specific tool fails to install:
  → The script will show which one failed
  → Manual install links are provided in the output
  → Other tools will still install and work

If Claude doesn't start on restart:
  → Check if Claude is installed: Open PowerShell, type "claude --version"
  → If not installed, run: npm install -g @anthropic-ai/claude-code
  → Restart again

If working directory is wrong:
  → The script checks these locations in order:
     1. %USERPROFILE%\Dropbox\Yoke Digital\yoke-assets--github-
     2. %USERPROFILE%\Dropbox\yoke-assets--github-
     3. %USERPROFILE%\Documents\GitHub\yoke-assets--github-
     4. D:\Dropbox\Yoke Digital\yoke-assets--github-
  → Make sure your yoke-assets folder is in one of these locations
  → Or edit startup-apps.ps1 to add your custom path
