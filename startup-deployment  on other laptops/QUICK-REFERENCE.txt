┌─────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING:                                        │
└─────────────────────────────────────────────────────────┘

  ❌ Script won't run
  → Right-click script → Run as Administrator
  → Or use INSTALL-ON-NEW-PC.bat

  ❌ Tailscale won't connect
  → Make sure auth-key.txt exists in folder
  → Or sign in manually from system tray

  ❌ GitHub Desktop needs login
  → Normal! Sign in once, it remembers

  ❌ Nothing auto-starts
  → Restart PC completely (not just logout)
