═══════════════════════════════════════════════════════════════════════
  🚀 COMPLETE SETUP PROCESS (5 SIMPLE STEPS)
═══════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────┐
│  STEP 1: Sign into Dropbox (5 minutes)                           │
└───────────────────────────────────────────────────────────────────┘

1. Open Dropbox (should already be installed)
2. Sign in with your credentials
3. Wait for initial sync to complete
   → Watch for: "Yoke Digital" folder to appear
   → Watch for: "yoke-assets--github-" folder inside it

Status: ⏳ WAIT for sync to finish before continuing
        You can work on other things while this syncs


┌───────────────────────────────────────────────────────────────────┐
│  STEP 2: Navigate to deployment folder (30 seconds)              │
└───────────────────────────────────────────────────────────────────┘

Open File Explorer and go to:
  C:\Users\[YourUsername]\Dropbox\Yoke Digital\yoke-assets--github-\
  startup-deployment  on other laptops\

Look for this folder ↑


┌───────────────────────────────────────────────────────────────────┐
│  STEP 3: Run the installer (5-10 minutes)                        │
└───────────────────────────────────────────────────────────────────┘

1. Right-click: SIMPLE-ONE-CLICK-INSTALL.bat
2. Select: "Run as administrator"
3. Click YES when Windows asks for permission
4. Watch the installation progress:
   [1/8] Checking administrator privileges
   [2/8] Checking Windows Package Manager (winget)
   [3/8] Checking Tailscale VPN
   [4/8] Checking GitHub Desktop (takes 2-3 mins)
   [5/8] Checking Node.js (takes 2-3 mins)
   [6/8] Checking Claude Code
   [7/8] Configuring Git
   [8/8] Setting up auto-startup apps

5. Window stays open - review what was installed
6. Press any key to close window when done


┌───────────────────────────────────────────────────────────────────┐
│  STEP 4: Restart the laptop (1 minute)                           │
└───────────────────────────────────────────────────────────────────┘

Restart → Start Menu → Power → Restart


┌───────────────────────────────────────────────────────────────────┐
│  STEP 5: First-time authentication (5 minutes)                   │
└───────────────────────────────────────────────────────────────────┘

After restart, these will auto-open:

1. ✓ GitHub Desktop
   → Sign in with your GitHub account
   → Authenticate when prompted

2. ✓ Tailscale
   → Should auto-connect
   → If not, click tray icon and sign in

3. ✓ Windows Terminal with Claude Code
   → Will prompt for Anthropic API key on first run
   → Enter your API key
   → Press Enter

DONE! Everything is now set up and will auto-start on future reboots.

═══════════════════════════════════════════════════════════════════════
  ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

"Dropbox folder not syncing"
  → Check internet connection
  → Check Dropbox is signed in (tray icon)
  → Right-click Dropbox icon → Settings → Check selective sync
  → Wait longer - large folders take time

"Installer closes immediately"
  → Right-click .bat file → Run as administrator
  → Don't just double-click

"Specific software fails to install"
  → Check internet connection
  → The installer shows manual download links
  → Other software still installs and works
  → You can install failed items manually later

"Claude doesn't start after restart"
  → Open PowerShell, type: claude --version
  → If not found, run: npm install -g @anthropic-ai/claude-code
  → Restart again

"Wrong working directory"
  → startup-apps.ps1 checks these locations:
    1. C:\Users\[user]\Dropbox\Yoke Digital\yoke-assets--github-
    2. C:\Users\[user]\Dropbox\yoke-assets--github-
    3. C:\Users\[user]\Documents\GitHub\yoke-assets--github-
    4. D:\Dropbox\Yoke Digital\yoke-assets--github-
  → Make sure folder is in one of these paths
