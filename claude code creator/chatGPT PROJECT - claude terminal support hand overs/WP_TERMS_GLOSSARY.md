# WordPress / ACF terms you will see

- Page (post_type=page): the thing you are editing.
- Page Title: top title field; also used for H1 sometimes, depending on theme.
- Slug/Permalink: URL identifier; avoid changing unless you intend to change the public URL.
- ACF Field Group: a set of custom fields shown on a page by Location Rules.
- Flexible Content field: ACF field that contains multiple "Layouts" (blocks/sections).
- Layout: a block type inside Flexible Content (e.g., hero, content_panel, cta_banner).
- Sub-fields: fields inside a layout (e.g., heading, subheading, body, buttons).
- WYSIWYG: rich text editor field (Visual/Text tabs).
